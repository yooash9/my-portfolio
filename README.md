# Personal Professional Portfolio Website

An interactive, responsive single-page personal portfolio showcasing my engineering background, technical stacks, and public works.

## 🚀 Key Functional Systems

### 1. Adaptive Chatbot Feature
- **Implementation Strategy**: Built native script-driven message logic using custom rule structures (`script.js`).
- **Functionality**: Evaluates user entry logs via string array parsing to look for key operational phrases (`'skills'`, `'projects'`, `'resume'`) and drops appropriate predefined responses cleanly into layout logs.

### 2. Live Dynamic QR Core
- **Integration**: Leverages the `QRCode.js` generation module.
- **Workflow**: Programmatically parses the environment's `window.location.href` to update real-time layout structures automatically upon load, enabling cross-device code delivery.

## 🌍 GitHub Pages Public Deployment Steps
1. Push all structural codes live up to a public GitHub repository.
2. Select **Settings** -> Locate the **Pages** menu column option.
3. Establish execution branch distribution targets directly tracking the **`main`** branch framework on the `/(root)` level path. 
4. Select **Save** to distribute production bundles live across explicit public URLs.
